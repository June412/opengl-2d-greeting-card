# OpenGL 2D Greeting Card

**CPT205 — Computer Graphics**

An interactive greeting card built with C++ and OpenGL. Find the cat with a lantern, guide it to the switch, and light up the campus with fireworks.

## Run

On Windows, run from the project folder:

```powershell
.\XJTLU.exe
```

Click the cat when prompted to begin. Move the mouse to control the lantern, use **W/A/S/D** or **arrow keys** to move, and press **Space** at the switch. Press **Q** to quit.
